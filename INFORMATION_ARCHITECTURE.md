# HADF Team Learning & Operations Portal — Information Architecture

Source of truth: **Hackathon Agentic Development Framework (HADF) - Master Team Handbook**, 146 pages.

## Design goal
Transform the handbook into two complementary experiences without weakening its meaning:

1. **Learn Mode** — prerequisite-first, progressive learning for a teammate who has never used HADF.
2. **Event Mode** — situation-first operational navigation for a live 24-hour hackathon.

The portal treats **HADF** as the human-governed engineering process framework. The repository, technology stack, agents, and humans are explicitly separated.

## Event Mode navigation

The event dashboard is organized by immediate situation rather than chapter order: challenge received, create problem.md, create plan.md, launch Builder, rendezvous, API contract changed, blocker, merge, migration conflict, broken main, QA P0, Golden-Path E2E, behind schedule, Feature Freeze, deployment failure, final four hours, Demo Freeze, judge preparation, submission.

## Cross-cutting navigation

- Role-based paths: Lead / Backend / Frontend / QA, with a 3-member mode toggle.
- Global client-side search across structured portal sections **and all 146 source pages**.
- Copy-ready prompts/templates/packets.
- Persistent localStorage checklists and learning progress.
- Full source reference for traceability.
